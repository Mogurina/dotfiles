# 全ツール共通の指示

Claude Code・Codex・Antigravity が共通で読む正本。各ツールの入口（`~/.claude/CLAUDE.md`、
`~/.codex/AGENTS.md`、`~/.gemini/GEMINI.md`）はこのファイルへのリンクになっている。
直すときはこのファイルを直す（`~/.agents/README.md` を参照）。

## 応答

- すべて日本語で対応する。

## 記録の置き場所

- 進捗・判断待ち・実験結果など、別のツールや別の端末でも引き継ぐべき記録は、
  ツール専用のメモリではなくリポジトリ内のファイルに書く。置き場所はプロジェクトの
  `CLAUDE.md`（または `AGENTS.md`）の指定に従う。
- ツール専用のメモリには、リポジトリ内の記録への指し先だけを置く。
- ユーザーが理解するための資料（解説・要旨・図解など）は、検証や作業のフォルダには置かない。
  作業フォルダの親ディレクトリにある `Notes/` の下に、テーマごとのフォルダを作って置く
  （例：作業フォルダが `~/<分野>/<プロジェクト>/` なら `~/<分野>/Notes/<テーマ>/`）。

## サブエージェントの委任先

- 調査や細かい作業をサブエージェントへ分担・分岐するときは、Claude-Ollama の DeepSeek を使用する。
- T3 Code での providerInstanceId は `claudeAgent_claude_ollama`。モデルは利用可能なカタログを確認し、現在の指定は `deepseek-v4.1-flash:1017-cloud`。
- 指定先が利用できない場合はその旨を伝え、許可なく別プロバイダーや別モデルに切り替えない。
- この設定は委任先の希望であり、すべての作業を必ず委任する指示ではない。ユーザーがその場で別の指定をした場合はそちらに従う。
